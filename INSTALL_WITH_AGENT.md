# Установка с помощью агента Codex

Скопируйте агенту этот запрос:

> Установи Antigravity MCP и skill `antigravity-research` из https://github.com/berish-ceo/antigravity-mcp для моего пользователя Codex. Прочитай `INSTALL_WITH_AGENT.md` в этом репозитории и следуй ему. Затем дополни `~/.codex/AGENTS.md` правилами использования Antigravity **только для research**. Если я указал другой путь к `AGENTS.md`, используй его. Проверь результат и покажи изменённые файлы и конфигурацию.

Этот запрос разрешает установку локальных компонентов и дополнение указанного `AGENTS.md`. Он не разрешает удалять или заменять существующие установки с другим содержимым.

## Порядок работы агента

1. Открой инструкции пользователя и проекта, выбранный `AGENTS.md` (если он существует) и текущую конфигурацию MCP. Определи ОС и версии Python, Codex и `agy`. Первая версия пакета проверяется на macOS; для других ОС сообщи о неподтверждённой совместимости до изменения системы. Нужны Python 3.10+ и авторизованный `agy` с доступной Gemini Flash 3.8+.
2. Если `agy` отсутствует, проверь актуальный способ установки в [документации Antigravity CLI](https://antigravity.google/docs/cli/install) и установи его. Если вход требует браузера или учётных данных, попроси пользователя выполнить этот интерактивный шаг. Не записывай токены или содержимое сессии в отчёт и репозиторий.
3. Клонируй этот репозиторий в свободный постоянный каталог пользователя, например `$HOME/.local/share/antigravity-mcp`. Если каталог уже существует, проверь его происхождение и состояние. Не перезаписывай пользовательские изменения. Создай `.venv` в клоне и установи `requirements.txt`.
4. Проверь `codex mcp get antigravity`. Если записи нет, добавь сервер командой из README. Если запись уже указывает на этот экземпляр, сохрани её. Если она указывает на другой сервер, остановись и покажи конфликт пользователю вместо замены. В `[mcp_servers.antigravity]` установи `tool_timeout_sec` выше используемого `timeout` (для стандартных 300 секунд достаточно 330). Сохрани остальные настройки `config.toml`.
5. Установи каталог `skills/antigravity-research` в `$CODEX_HOME/skills/antigravity-research` (обычно `~/.codex/skills/antigravity-research`). Если каталог уже есть, сравни содержимое и не заменяй отличающуюся версию без решения пользователя.
6. Дополни **только** выбранный `AGENTS.md`. Если файла нет, создай его. Если раздел Research уже есть, добавь в него блок ниже. Если нет, создай раздел `## Research` и добавь блок. Если в разделе есть противоречащее правило, покажи его пользователю и согласуй изменение. Повторный запуск не должен дублировать блок. Сохрани остальное содержимое и покажи diff.
7. Запусти тесты из README, проверь `codex mcp get antigravity` и наличие установленного `SKILL.md`. После обновления подключения MCP проверь, что доступны `antigravity_grounded_search` и `antigravity_fetch_url`. Если текущая сессия Codex не обновляет список инструментов, попроси открыть новую сессию и не утверждай, что проверка MCP прошла.

## Блок для `AGENTS.md`

```markdown
<!-- antigravity-research:start -->
- Для актуального веб-исследования используй skill `antigravity-research`: начинай поиск с `mcp__antigravity__antigravity_grounded_search`, а чтение выбранного URL — с `mcp__antigravity__antigravity_fetch_url`.
- Проверяй существенные выводы по первоисточникам. Если соответствующий вызов Antigravity окончательно завершился ошибкой, вернул `FALLBACK_REQUIRED`, исчерпал таймаут или недоступен, используй доступный штатный инструмент и назови причину перехода.
- Это правило относится только к research и само по себе не разрешает запуск managed turns. Для них следуй запросу пользователя и действующим правилам делегирования.
<!-- antigravity-research:end -->
```

В отчёте перечисли фактически выполненные шаги, точные пути установки, проверки и оставшиеся ограничения. Не публикуй репозиторий и не отправляй данные пользователя во внешние сервисы помимо необходимых операций установки, авторизации и запрошенной проверки research.
