# Подключить персональный прокси

MCP и CLI остаются на Mac. Настройка указывает `agy` **адрес настоящего удалённого прокси**: ни SSH-доступ, ни локальный порт, ни opencodex для этого не нужны. Каждый пользователь входит в собственный аккаунт Antigravity и получает отдельную учётную запись прокси.

**Если прокси уже есть.** Попросите у администратора полный персональный URL вида `https://USER:PASSWORD@proxy.example.org:443`. Сертификат должен быть доверенным на Mac и соответствовать имени или IP. Спецсимволы в имени и пароле должны быть закодированы для URL. Не вставляйте адрес с паролем в чат, git, историю shell или командную строку.

**Если прокси нет.** Администратор один раз [поднимает сервис на сервере](proxy-server.md) и выдаёт каждому свой URL по защищённому каналу. Пользователям не нужно устанавливать серверную часть.

1. [Установите или обновите MCP и skill](../INSTALL_WITH_AGENT.md). Из корня проверенного клона выполните:
   ```sh
   python3 scripts/configure_proxy.py
   ```
   Вставьте личный URL в скрытое приглашение. Скрипт запишет его в `~/.config/antigravity-mcp/proxy-url` с правами `0600`.
2. В существующую таблицу `[mcp_servers.antigravity]` файла `~/.codex/config.toml` добавьте строку ниже. Если `env` уже задано, добавьте поле в него; прежнее поле `AGY_PROXY_URL` удалите. Не дублируйте таблицу и не меняйте имя MCP.
   ```toml
   env = { AGY_PROXY_FILE = "~/.config/antigravity-mcp/proxy-url" }
   ```
   Для прокси без секрета также допустимо `AGY_PROXY_URL` вместо файла. Если прокси не нужен, не задавайте ни одну из двух настроек. В этом случае `agy` наследует обычное окружение.
3. Перезапустите Codex Desktop. Попросите `antigravity_grounded_search` найти официальный сайт Google Antigravity и вернуть ссылку. Проверьте, что сработал этот инструмент, а не запасной поиск.

**Проверка внешнего IP.** В zsh выполните нижеописанную команду и сравните вывод с IP сервера администратора. Пароль не попадает в аргументы curl. На macOS используйте curl с поддержкой HTTPS-прокси (`curl --version`, функция `HTTPS-proxy`).
```zsh
( unset http_proxy HTTP_PROXY https_proxy HTTPS_PROXY all_proxy ALL_PROXY no_proxy NO_PROXY
  export https_proxy="$(<~/.config/antigravity-mcp/proxy-url)"
  curl -fsS --max-time 20 https://checkip.amazonaws.com )
```

**Запуск CLI вручную.** Установка MCP не меняет обычную команду `agy`. Если нужно, чтобы она тоже пользовалась тем же прокси, добавьте в `~/.zshrc` функцию и откройте новое окно терминала:
```zsh
agy() {
  local p
  p=$(<"$HOME/.config/antigravity-mcp/proxy-url") || return 1
  [[ -n "$p" ]] || return 1
  http_proxy="$p" https_proxy="$p" all_proxy="$p" HTTP_PROXY="$p" HTTPS_PROXY="$p" ALL_PROXY="$p" \
    NO_PROXY=localhost,127.0.0.1,::1 no_proxy=localhost,127.0.0.1,::1 command agy "$@"
}
```
Проверьте: `agy --print 'Ответь только OK'`. Настройки распространяются на `agy` и его дочерние процессы. Код он читает с вашего диска; фрагменты, нужные для ответа, могут отправляться модели. Для отмены удалите поле прокси из таблицы MCP и функцию zsh, перезапустите Codex и терминал. HTTP 407 указывает на неверные или отозванные данные прокси; ошибка сертификата требует исправить доверие или сертификат, а не выключать TLS-проверку.
