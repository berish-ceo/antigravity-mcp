# Переход с SSH-туннеля на прямой прокси

Актуальная [инструкция для Mac](proxy-client.md) использует персональный адрес удалённого HTTPS-прокси. Настройте его и проверьте IP и поиск, затем можно убрать старый туннель. Если устанавливали LaunchAgent именно из прежней версии этого репозитория, остановите `local.antigravity.socks` через `launchctl bootout "gui/$(id -u)/local.antigravity.socks"` и удалите только его plist из `~/Library/LaunchAgents`. Другие SSH-службы менять не нужно.
